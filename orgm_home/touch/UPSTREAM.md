# Upstream attribution

Independent adaptation of the keyboard panel/layout/key interaction approach in
end-4/dots-hyprland, commit2f2a376fdb2ad738bf55f693dd0b474b64bb0ab8:
https://github.com/end-4/dots-hyprland/tree/2f2a376fdb2ad738bf55f693dd0b474b64bb0ab8/dots/.config/quickshell/ii/modules/ii/onScreenKeyboard

Original authors: end-4 and dots-hyprland contributors. GPL-3.0; see LICENSE.
This adaptation replaces shell-specific dependencies, global focus grabs and
Ydotool with a standalone panel/controller and an unprivileged input engine.
Spanish Latin American key positions follow xkeyboard-config latam(basic).
No whole desktop shell, upstream sync engine or uinput permission is installed.
